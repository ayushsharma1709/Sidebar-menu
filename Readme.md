# Sidebar Menu Project

This is my first web development project built using HTML and CSS.

The project features a responsive sidebar navigation menu with smooth transitions and hover effects. It includes a toggle button to open and close the sidebar, along with styled menu items and social media icons.

Through this project, I learned:
- CSS positioning (absolute & fixed)
- Transitions and hover effects
- Sidebar UI design
- Working with icons and layouts

I will continue improving this project as I learn more advanced concepts.
